# Altimeter

Displays altitude calculated from atmospheric pressure.

## Display

Shows altitude, Air pressure at sea level and temperature of the internal temperature sensor.
The display updates continuously when unlocked.
If locked the readings update only once every minute to save energy.

## Usage

Swipe up or down (when unlocked) to correct the altitude / pressure.
Touch the screen center or press the (middle) button to reset altitude / pressure to default.
